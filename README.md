# GHOUL — pixel RPG (Tokyo Ghoul fan game)

Мобильная пиксельная RPG для браузера. Без сборки и зависимостей: обычные HTML/CSS/JS.

## Запуск
Открой `index.html` в браузере (на телефоне или на компьютере).
Лучше через локальный сервер, чтобы не было проблем с загрузкой файлов, например:

    python3 -m http.server 8000
    # затем открыть http://localhost:8000

Для шрифта (Press Start 2P) нужен интернет, без него подставится обычный моноширинный.
Управление: джойстик слева, кнопки KAGUNE / DASH / SUPER справа. На клавиатуре: WASD или стрелки, пробел (атака), Shift (рывок).

## Заметки
- Скрипты не используют модулей: все файлы делят одну глобальную область видимости, поэтому порядок подключения в `index.html` важен.
- Позиции кадров в `atlas.png` заданы константами в `js/02_assets.js` (`*_Y`, `FW`, `FH`) и функцией `charSY`.
- Звуки и музыка генерируются кодом (Web Audio), аудиофайлов нет.
- Монеты, улучшения и купленные предметы действуют в рамках одной игры и не сохраняются.
